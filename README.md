# sppt-blur-extension

- "입력 블러 여부" 옵션을 통해 테이블 셀 내부에 input이 있을 때 blur 적용 여부를 제어할 수 있습니다.

## 주요 기능

### 1. 일반 테이블 블러

- 일반적인 테이블(`.table-common` 등)에 대해 지정한 컬럼을 제외하고 셀을 blur 처리합니다.
- 옵션:
  - **공백 셀 블러 여부**: 내용이 없는 셀도 blur 처리할지 여부
  - **입력 블러 여부**: 셀 내부에 `<input>`이 있을 때 blur 처리할지 여부
  - **제외 컬럼**: blur에서 제외할 컬럼명(쉼표로 구분)
  - **포함 컬럼**: blur를 반드시 적용할 컬럼명(쉼표로 구분)

### 2. 수평 테이블 블러

- `.table-common.horizon` 클래스를 가진 수평 테이블에 대해 blur를 적용합니다.
- 옵션:
  - **공백 셀 블러 여부**: 내용이 없는 셀도 blur 처리할지 여부
  - **입력 블러 여부**: 셀 내부에 `<input>`이 있을 때 blur 처리할지 여부
  - **제외 컬럼**: blur에서 제외할 컬럼명(쉼표로 구분)

### 3. 셀렉터 리스트 블러

- 입력한 CSS 셀렉터에 해당하는 요소들을 blur 처리합니다.
- 옵션:
  - **셀렉터 리스트**: 쉼표로 구분된 CSS 셀렉터 목록

### 4. 행정 2차 현황 테이블 블러(PrimeVue)

- PrimeVue의 `.p-datatable-table`에 대해 blur를 적용합니다.
- 옵션:
  - **공백 셀 블러 여부**: 내용이 없는 셀도 blur 처리할지 여부
  - **제외 컬럼**: blur에서 제외할 컬럼명(쉼표로 구분)

### 5. 통합 실행

- 여러 blur 기능을 한 번에 실행할 수 있습니다.
  - **상세블러실행**: 일반 테이블 블러 + 수평 테이블 블러
  - **현황블러실행**: 행정 2차 현황 테이블 블러 + 셀렉터 리스트 블러
  - **전체실행**: 모든 blur 기능 실행

---

- 각 입력값은 localStorage에 자동 저장/복원됩니다.
- 각 입력 옆의 '초기화' 버튼으로 해당 입력값과 저장값을 삭제할 수 있습니다.
